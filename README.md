# Priyanshu Mishra

**CPU / SoC Design Verification Engineer | RISC-V | DSP/ASIP HW/SW Co-Verification**

I am a design-verification engineer with nearly five years of experience across RISC-V processors, SoC IP, and custom DSP/ASIP hardware/software co-verification. My work spans architecture and verification planning, SystemVerilog/UVM, software-driven tests, ISS-to-RTL correlation, regression debug, and subsystem integration.

## Current work

At ACL Digital, I work on a Renesas client project involving verification of a custom DSP/ASIP generated with Synopsys ASIP Designer. This includes compiler-generated workloads, ISS-to-RTL functional and architectural correlation, RISC-V cryptographic workloads, and MCU boot and interrupt flows.

## Technical focus

- **Processor architecture:** RISC-V RV32/RV64, pipelines, LSU, MMU/TLB, caches, privilege modes, exceptions, and virtual memory.
- **Design verification:** SystemVerilog, Verilog, UVM, directed and constrained-random testing, functional coverage, assertions, regression automation, and waveform debug.
- **DSP/ASIP HW/SW co-verification:** C/C++, RISC-V assembly, GCC/Clang/Chess compiler flows, ISS-to-RTL correlation, and compiler-driven tests.
- **SoC verification:** AXI, AHB, APB, DMA/eDMA, MMU/TLB, LLC, arbitration, TrustZone, and subsystem integration.
