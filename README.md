## What I work on

I’m a design-verification engineer with nearly five years of experience across RISC-V processors, SoC IP, and custom DSP/ASIP hardware/software co-verification.

At ACL Digital, I work on a Renesas client project verifying a custom DSP/ASIP. My current work includes compiler-generated workloads, ISS-to-RTL correlation, RISC-V cryptographic tests, and MCU boot and interrupt flows.

| Processor verification | SoC and subsystem verification |
| --- | --- |
| RISC-V RV32/RV64, pipelines, LSU, MMU/TLB, caches, privilege modes, and virtual memory | SystemVerilog/UVM, coverage, assertions, AXI/AHB/APB, DMA/eDMA, TrustZone, and integration |

## A research idea, from notebook to proposal

I’m exploring how memory scheduling and last-level-cache allocation affect an RISC-V CPU and an inference accelerator under mixed workloads. It’s an **early research proposal**; implementation, simulation, and measured results remain future work.
